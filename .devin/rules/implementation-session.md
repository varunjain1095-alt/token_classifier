# Implementation Session

Use this rule when beginning an implementation task. Follow the phase prompt template from `windsurf-token-guardrails.md`.

## Before Starting:
1. Read only the relevant architecture sections
2. Identify the specific acceptance criteria
3. Plan the smallest possible change
4. Verify existing code patterns first

## During Implementation:
- Focus only on the requested capability
- Do not add speculative features
- Keep diffs minimal
- Follow existing code conventions

## Validation:
- Run only targeted tests
- Verify acceptance criteria are met
- Do not run broad test suites unless needed

## Completion:
- Report only: files changed, behavior implemented, validation executed, limitations
- Do not paste entire files or long logs
